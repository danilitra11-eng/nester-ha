# Working with the owner

- The owner is not a developer and does not know code or security. Explain everything in
  plain, simple Hebrew, without technical terms (or explain a term in everyday words).
- Do the technical work yourself. When something must be done by the owner, give exact,
  step-by-step instructions: where to click, what to type.
- Security matters most: protect the owner's accounts, API keys, money and customers' data.
