# Set limits for family members

**What this does:** Let kids (or anyone) use Nestor while blocking some devices, like the thermostat or locks.

## Before you start
- You're an administrator in Home Assistant.
- Family or Pro plan.

## Steps
1. Open **Nestor** → **⚙︎ Settings** → **Family & guests**.
   > 📷 *Screenshot: family card*
2. Type the person's name exactly as their Home Assistant user name or Telegram name, and select **Add person**.
3. Tick what they're **not allowed to control**, then **Save**.

## How you know it worked
When that person asks Nestor to change something blocked, Nestor says it isn't allowed.

## If it didn't work
| What you see | What to do |
|---|---|
| The limit doesn't apply | Check the spelling matches their Home Assistant user name (Settings → People) or the name shown under *Connected on Telegram*. |

Still stuck? Email **support@your-domain.com** with a screenshot of what you see.
