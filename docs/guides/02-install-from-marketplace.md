# Install Nestor from the Marketplace

**What this does:** Download Nestor into your Home Assistant.

## Before you start
- Home Assistant 2025.6 or newer (Settings → About shows your version).
- You're logged in to Home Assistant as an administrator.

## Steps
1. In Home Assistant, open **Settings → Marketplace**.
   > 📷 *Screenshot: Settings menu with Marketplace*
2. Search for **Nestor** and open **Nestor AI Butler**.
   > 📷 *Screenshot: search result*
3. Select **Download**, then **Download** again to confirm.
   > 📷 *Screenshot: download dialog*
4. If Nestor doesn't show up in search yet: select **⋮ → Add from a GitHub link**, paste `https://github.com/danilitra11-eng/nester-ha`, select **Add**, then continue from step 3.
   > 📷 *Screenshot: Add from a GitHub link dialog*
5. Restart Home Assistant (next guide).

## How you know it worked
Nestor appears under **Settings → Marketplace → Downloaded**.

## If it didn't work
| What you see | What to do |
|---|---|
| "holds apps, the Marketplace does not install apps" | You're using an old link. Use `https://github.com/danilitra11-eng/nester-ha` exactly. |
| No Marketplace in Settings | Update Home Assistant to the latest version (Settings → System → Updates). |

Still stuck? Email **support@your-domain.com** with a screenshot of what you see.
