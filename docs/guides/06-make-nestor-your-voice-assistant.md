# Make Nestor your voice assistant

**What this does:** Phones, watches and voice speakers talk to Nestor instead of the basic built-in assistant.

## Before you start
- Nestor is set up.

## Steps
1. This normally happens automatically during setup (step 6). To check: **Settings → Voice assistants**.
   > 📷 *Screenshot: voice assistants list*
2. You should see an assistant with your butler's name, marked **Preferred**. If not, open Nestor → **⚙︎ Settings → Permissions**, tick **Use Nestor as my voice assistant**, and select **Save**.
3. Optional: to use a different microphone engine or wake word, select the assistant and change **Speech-to-text** or **Wake word**. Don't change **Conversation agent**.
   > 📷 *Screenshot: assistant settings*

## How you know it worked
Ask your phone app's Assist (the 💬 / 🎤 button) "what's your name?" — it answers with your butler's name.

## If it didn't work
| What you see | What to do |
|---|---|
| Assist answers like before, without the name | Make sure the Nestor assistant is marked **Preferred** (select it → ⋮ → Set as preferred). |
| Your voice speaker still uses the old assistant | Open the speaker's device page and set **Assistant** to Nestor. |
