# Undo a dashboard change

**What this does:** Go back to how a dashboard looked before Nestor changed it.

## Before you start
- Nestor has the **🎨 Dashboards & themes** permission.

## Steps
1. Ask Nestor: "undo the last change to the *(dashboard name)* dashboard".
2. Nestor restores the previous version. Ask again to go back further — it keeps the last 10 versions.

## How you know it worked
Open the dashboard — it looks like it did before.

## If it didn't work
| What you see | What to do |
|---|---|
| "There is no earlier version" | Nestor only keeps versions of changes it made itself. |
| A new dashboard you don't want | Ask "delete the *(name)* dashboard" and confirm. Nestor can only delete dashboards it created. |

Still stuck? Email **support@your-domain.com** with a screenshot of what you see.
