# Nestor AI Butler

Talk to your home like you'd talk to a person — by text or voice, in English, Spanish or any major language — and Nestor runs it.

- "Turn off everything downstairs and set the bedroom to 70"
- "Cierra las persianas de la sala y prende la cocina a la mitad"
- "Is the garage door closed? What's the temperature outside?"

Understands rooms and devices by their everyday names, handles several devices in one sentence, and only touches the device types you allow.

Requires an active subscription — see the Documentation tab.
